# BoonEdits

A Hades II mod that reworks and rebalances over 30 boons. Every change is independent and can be
switched off on its own.

Check out the [companion mod, MoreDuos](https://thunderstore.io/c/hades-ii/p/SWu/MoreDuosMod/)!

## Features

- Reworks various boons and some keepsakes — see the Wiki tab for the full
  list.
- One toggle per change in `ReturnOfModding/config/SWu-BoonEdits.cfg`, fully configurable.

## Install

Install through a mod manager (Thunderstore or r2modman) to pull in dependencies.

To install by hand, drop the folder into `ReturnOfModding/plugins/` and make sure these are present:
Hell2Modding, ENVY, Chalk, ReLoad, SJSON and ModUtil.

## Configuration

Launch the game once to generate `ReturnOfModding/config/SWu-BoonEdits.cfg`, then configure (enable/disable) any boon edits. 

`Experimental` changes are off by default (includes limited support for Zagreus' Journey and Wrath of Olympus) -- enable at your own risk!

Be sure to relaunch the game each time you make changes to the config.
